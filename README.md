## Entry

`main.py` (Python 3, stdlib only) writes a single nostalgic childhood
memory sentence — at most 280 characters — to `entry.txt`:

> Every rainy afternoon my grandmother lifted the lid off the rice pot, and the steam fogged her glasses while she pretended not to notice me stealing the crispy crust from the bottom.

## Run

```sh
python3 main.py
```

It reads `MAKEFUN_INPUT_DIR` / `MAKEFUN_OUTPUT_DIR` (falling back to
`/input` / `/output`) and writes `entry.txt` inside the output directory.
The output is fixed and deterministic.
